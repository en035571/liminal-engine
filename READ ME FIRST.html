Liminal Engine

Music-driven visuals and CRT treatments, running on your own Mac.

Everything happens locally. Nothing is uploaded anywhere. Setup takes about five minutes, once. Version 2026.11.25.2.

What you need

MacmacOS 13 or newer. Apple Silicon (M1 or later) is fastest; Intel works.
DiskAbout 2 GB free.
InternetDuring setup, and to fetch updates.

Set up

  1. Keep this folder together.

    Move the whole Liminal Engine folder wherever you like, for example Applications or Documents. The app only works next to its files.

  2. Right-click Set Up and choose Open.

    macOS warns that it's from an unidentified developer; choose Open again. A Terminal window installs what the engine needs and asks two yes/no questions. Press Return to accept each. If it asks to install Python or ffmpeg with Homebrew, say yes.

  3. Open Liminal Engine.

    The first time, right-click it and choose Open, for the same reason. After that a normal double-click works.

No Homebrew? Setup will open brew.sh. Paste the one line from that page into Terminal, then run Set Up again.

The five tools

Latent DreamAn AI model dreams to a song: the music drives the motion. Set Up downloads a first model (microscope images); the Models page has more.
CollageTurns folders of stills and clips into a moving-stills collage, held on the beat of a song, in three styles.
Cut BankChops your footage to the beats of a song, with treatments on each shot.
GranularRuns one clip through painterly grain looks (granular, paint, outline). Add a song and its loudness can drive the grains.
CRTPuts any image or video through a simulated tube TV, tape deck and camera. Try the presets in Look.

Using it

Bring your own files
Drag images, videos and songs straight onto the window.
Start with a test
Latent Dream renders about two frames a second, so a whole 3-minute song takes around half an hour. Run the 15-second test first.
Where renders go
Movies › Liminal Engine, one folder per tool. The Renders folder button opens it.
Closing
Closing the window stops the engine and any render in progress.

Updates

No need to download it again
When a new version is out, a bar appears at the bottom of the window. Click Update: it downloads only what changed and the app reopens itself, usually within a minute. Later hides it until next time.
What's safe
Your renders, models and uploads are never touched. Replaced files are kept in the _cleanup folder here, and if an update fails part way the old version is put back.
Not during a render
The update waits until the render or model download is finished.

If something goes wrong

"Can't be opened because Apple cannot check it"
Right-click the file and choose Open. Or open System Settings › Privacy & Security, scroll down and click Open Anyway.
"Liminal Engine is not set up yet"
Run Set Up first (step 2). If it stopped with an error, run it again; it continues where it left off.
Granular says OpenCV is missing
Run Set Up again; it adds it.
Latent Dream says PyTorch is missing
You skipped it during setup. Run Set Up again and answer yes.
An update didn't finish
The bar says why, and nothing was changed. Check the internet connection and click Try again.
The window is blank or a tool does nothing
Quit the app and open it again. If a render failed, the red line under the Render button says why.
