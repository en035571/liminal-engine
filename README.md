# Liminal Engine

Music-driven visuals and CRT treatments that run on your own Mac.

**Download:** [Liminal-Engine.zip](https://github.com/en035571/liminal-engine/releases/latest/download/Liminal-Engine.zip), unzip it,
then open `READ ME FIRST.html` inside. Setup takes about five minutes, once. After that, new versions arrive inside
the app (a bar at the bottom of the window); you don't download it again.

Needs macOS 13 or newer. Apple Silicon is fastest.

`models/stylegan2-ada-pytorch` is NVIDIA's StyleGAN2-ADA code under its own licence (see the LICENSE.txt in that folder).
